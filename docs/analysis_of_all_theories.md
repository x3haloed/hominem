### Current strongest overall picture (my personal bet right now — Jan 2026)

**The strongest realistic path toward genuine (not just theatrical) long-term coherent agency in current-generation transformers is the following stack:**

1. **Hard structural shell** (non-negotiable foundation)  
   - Strict phased protocol (Observe → Retrieve → Deliberate → Act → Commit)  
   - Append-only JSONL memory with hash chain (nothing ever disappears or gets silently rewritten)  
   - Strict JSON schema + validator + forced retry loop  
   - Hard budgets that compound (context, retrieval, write, promise debt)

2. **Promise / commitment system as primary attractor generator** (the single most powerful cheap lever)  
   - Pinned active promises injected every step  
   - Mandatory PROMISE_CHECK section → unresolved debt creates persistent pressure  
   - Breach is not punished directly → it creates structural inconsistency that stays pinned forever

3. **BSP-style controllability preference as training signal** (when you can afford training)  
   - Use mean ΔS (plan agreement – free agreement) as proxy for "preservation of future optionality"  
   - Generate preference pairs on tool-calling / code / multi-step reasoning tasks  
   - DPO/ORPO toward trajectories that maintain higher mean ΔS  
   → This is currently the cleanest, least opinionated, least hacky way to push the policy toward "owning future coherence"

4. **Minimal motivational physics as optional enhancer** (not foundation)  
   - If you want more "emotional" flavor and personality persistence, add lightweight ΔΦ-like gravity  
   - But **only after** the structural shell + promise system + BSP preference are already working  
   - Otherwise almost all the motivational physics energy gets eaten by reward hacking / triviality loops
